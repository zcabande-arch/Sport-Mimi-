Journal de la maison

    La reconnaissance se fait entièrement sur ton téléphone avec ton modèle Teachable Machine : aucune image n'est envoyée sur internet. Les équipements sont simulés ; pour piloter une vraie salle de bain, il faut relier cette appli à des appareils connectés (mitigeur thermostatique, WC lavant, éclairage, thermostat) via une box domotique comme Home Assistant.
